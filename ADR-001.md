# Gym Pad

## Context
Tracking workout plans and weight on exercises is difficult and gets lost in notes along with the data is not pretty to look at. Also, if I write it on my laptop or my phone the data is not synced and could be outdated. The app should be accurate, available, and simple to use with most functionality abstracted. 

## Decision
We are going to use a serverless architecture as the app is going to most be read/write functions to change weight, read workout plan, or add a workout plan. Using Vercel as the hosting platform as it supports serverless designs and can be used for free. Database is going to be Supabase as it keep future options available such as image storing or video storing if wanted and avoiding a migration plan to be made. 

## Alternatives
- EC2 service to host, expensive

## Risks
- Cold starts add a delay
